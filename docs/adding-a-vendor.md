# Adding A Vendor

1. Collect official source URLs or clear public evidence.
2. Open a vendor request issue or a pull request with the proposed vendor facts.
3. Mark docs access, confidence, countries, and unknowns honestly.
4. Add or update eval prompts when agent behavior changes.
5. Wait for maintainer review and approval before publication.

Submissions are not published automatically. Do not add unsupported claims, private documents, credentials, or customer data.
